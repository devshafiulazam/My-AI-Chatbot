# AI Bibliography Chatbot

This is a local AI Chatbot built with Python 3.14 (compatible), Streamlit, and Ollama.

## Setup Instructions

1. **Install Requirements:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Run Ollama:**
   Make sure your Ollama service is running and the model is pulled.
   ```bash
   ollama pull llama3.1
   ```
3. **Run the App:**
   ```bash
   streamlit run app.py
   ```

## Credentials
Check the `.env` file for Admin Dashboard login details.
