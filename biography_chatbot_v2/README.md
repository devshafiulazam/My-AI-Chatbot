# AI Biography Chatbot

This is a visually stunning, highly interactive local AI Chatbot built with Python, Streamlit, and Ollama. It acts as a Biographical knowledge base.

## Setup Instructions

1. **Install Requirements:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Run Ollama:**
   ```bash
   ollama pull llama3.1
   ```
3. **Run the App:**
   ```bash
   streamlit run app.py
   ```
