# AI Biography Chatbot with Admin Panel

## Features
- **Chatbot Interface:** Interactive chat system.
- **Admin Dashboard:** Train the AI by adding new biographies dynamically.
- **Secure Login:** `.env` based credentials.

## Setup Instructions
1. Install dependencies: `pip install -r requirements.txt`
   *(Make sure to install because `python-dotenv` is newly added)*
2. Check `.env` file for Admin Username and Password.
3. Run the app: `streamlit run app.py`
