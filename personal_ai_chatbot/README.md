# Personal AI Chatbot (Local & Cloud)

একটি আধুনিক ডার্ক থিমযুক্ত পার্সোনাল AI চ্যাটবট অ্যাপ্লিকেশন, যা লোকাল Ollama এবং ক্লাউড API (Groq/OpenAI) উভয় ব্যাকএন্ড সমর্থন করে।

## ইনস্টলেশন ও রান করার নিয়ম:

1. **ফাইলগুলো আনজিপ করুন:**
   যেকোনো ফোল্ডারে জিপ ফাইলটি এক্সট্র্যাক্ট করুন।

2. **প্রয়োজনীয় প্যাকেজ ইনস্টল করুন:**
   টার্মিনাল বা কমান্ড প্রম্পটে গিয়ে নিচের কমান্ডটি দিন:
   ```bash
   pip install -r requirements.txt
   ```

3. **লোকাল Ollama চালু রাখুন (Local ব্যবহারের ক্ষেত্রে):**
   ```bash
   ollama serve
   ```
   (আপনার কাঙ্ক্ষিত মডেল যেমন `qwen3:0.6b` ডাউনলোড করা থাকতে হবে: `ollama run qwen3:0.6b`)

4. **চ্যাটবট চালু করুন:**
   ```bash
   streamlit run app.py
   ```
